# API существующего приложения

Ответ: `{"data": ...}`; ошибка: `{"error": "описание"}` с соответствующим
HTTP-статусом. JSON UTF-8. Заголовок `X-Demo-User: 1` выбирает Анну,
`2` — Бориса, `3` — Веру. По умолчанию 1. Это открытый демо-переключатель,
не доказательство личности; локальный API не предназначен для публикации в сеть.

| Метод и путь | Текущее поведение |
|---|---|
| `GET /api/health` | Проверка запуска сервиса |
| `GET /api/context` | Демо-пользователи, выбранный пользователь, время UTC и дата создания демо |
| `GET /api/projects` | Только проекты текущего пользователя, участники и количество задач |
| `GET /api/attention` | Задачи, требующие внимания руководителя его активных проектов |
| `GET /api/projects/{id}/tasks` | Все задачи доступного проекта |
| `POST /api/projects/{id}/tasks` | Создать задачу в активном проекте |
| `GET /api/tasks/{id}` | Доступная задача с комментариями и авторами |
| `PATCH /api/tasks/{id}` | Изменить поля с проверкой версии |
| `POST /api/tasks/{id}/comments` | Добавить комментарий в активном проекте |

Поля задачи для создания и изменения: `title`, `description`, `status`,
`assignee_id`, `due_at`. При создании `title` обязателен. Неизвестные поля
отклоняются. Исполнитель — участник проекта или `null`. Даты — строго
`YYYY-MM-DDTHH:mm:ssZ` либо `null`; текущий UI редактирует их с точностью до минуты.
Для PATCH обязательно целое поле `version`, полученное при чтении.
Успешное изменение увеличивает версию; устаревшая версия возвращает 409.
Комментарий принимает `{"body":"текст"}`.

Максимумы строк в байтах UTF-8: название 200, описание 10000, комментарий 5000.
Максимум тела изменения — 32 KiB. Ошибка валидации — 422, JSON — 400,
неизвестный пользователь — 401, отсутствующий или недоступный объект — 404,
запись в архив — 409. Поиск и фильтр статуса в текущем UI выполняются локально.

Элемент списка `GET /api/attention` содержит `task` (обычные поля задачи
без полной переписки), `project_id`, `project_name`, массив `signals`
и `evidence`. Поддерживаются причины `blocked`, `overdue`, `needs_help`,
`due_soon`. Если сработало правило по комментарию, `evidence` содержит
`id`, `author`, `body` (отрывок текста) и `created_at`; иначе это `null`.
Для доступа к полному обсуждению используется `GET /api/tasks/{id}`.
Пустой список возвращается как `{"data":[]}`.
